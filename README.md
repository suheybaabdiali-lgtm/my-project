# Budget Tracker

## What I Built

I built a simple Budget Tracker webpage that allows users to enter and organize their expenses.

The page includes an expense form, an expense table, a budgeting tips video, and styling using CSS.

## Project Files

### index.html

The `index.html` file contains the structure of the Budget Tracker.

It includes:

- A page heading and budget tracker icon
- An expense form
- Expense name and amount inputs
- A category dropdown with five options
- An Add Expense button
- An expense table with a table header and body
- A How To Use section
- An embedded budgeting video

### style.css

The `style.css` file controls the appearance of the Budget Tracker.

It includes:

- Element selectors
- Class selectors
- ID selectors
- Form styling
- Table styling
- `:hover` effects
- `:focus` effects
- `:nth-child()` styling
- Descendant selectors

## Technologies Used

- HTML5
- CSS3

## Project Purpose

The purpose of this project is to practice HTML structure, forms, tables, multimedia elements, and advanced CSS selectors while creating a simple and useful Budget Tracker.
